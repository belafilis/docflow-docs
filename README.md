# DocFlow Documentation

Документация демонстрационной системы электронного согласования документов.

## О проекте

DocFlow — вымышленный B2B-сервис для создания,
согласования и подписания электронных документов.

## Целевая аудитория

- Сотрудники организаций
- HR-специалисты
- Руководители подразделений
- Администраторы системы

## Основные возможности

1. Создание заявлений
2. Настройка маршрутов согласования
3. Подписание документов
4. Отслеживание статусов

## Структура документации

| Раздел | Назначение |
|---|---|
| Начало работы | Первое знакомство с системой |
| Руководство пользователя | Основные пользовательские сценарии |
| Администрирование | Настройка системы и прав доступа |
| Справочная информация | Статусы, ошибки и ограничения |
