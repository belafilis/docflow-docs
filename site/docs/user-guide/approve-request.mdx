# Согласование заявления

## Перед началом

Для согласования заявления необходима соответствующая роль в системе.

## Порядок действий

1. Откройте раздел «Заявления».
2. Выберите заявление со статусом «На согласовании».
3. Проверьте сведения в заявлении.
4. Нажмите «Согласовать».

## Результат

Статус заявления изменится на «Согласовано».
