# Согласование заявления

## Перед началом

Для согласования заявления необходима роль «Руководитель» или «HR-специалист».

:::info[Проверка прав доступа]

Если кнопка «Согласовать» недоступна, обратитесь к администратору системы для проверки назначенной роли.

:::

## Порядок действий

1. Откройте раздел «Заявления».
2. Выберите заявление со статусом «На согласовании».
3. Проверьте сведения в заявлении.
4. Нажмите «Согласовать».

## Результат

Статус заявления изменится на «Согласовано».
